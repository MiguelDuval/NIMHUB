# NIM Hub — GitHub Actions setup

## 1. Create the NVIDIA API key

Open NVIDIA Build API Keys:
https://build.nvidia.com/settings/api-keys

Create or copy an NVIDIA API key there. Treat it like a password. Do not put it in README, source code, .env committed to git, workflow YAML, or an APK.

## 2. Add the key to this repository

On GitHub open the repository MiguelDuval/NIMHUB.

Go to Settings -> Secrets and variables -> Actions.
Open the Secrets tab under Repository secrets.
Click New repository secret.
Name: NVIDIA_API_KEY
Secret: paste the NVIDIA API key.
Click Add secret.

GitHub documents repository secrets here:
https://docs.github.com/en/actions/how-tos/write-workflows/choose-what-workflows-do/use-secrets

## 3. Check that the secret exists

GitHub will not show the secret value again. This is expected.
You can see the secret name in Settings -> Secrets and variables -> Actions, but not its value.

## 4. Test NVIDIA access from GitHub

Open Actions in this repository.
Run the workflow named NVIDIA NIM smoke test manually with Run workflow.
The workflow calls NVIDIA /v1/models only when NVIDIA_API_KEY exists.

This proves that GitHub Actions can authenticate to NVIDIA. The key is not sent to the Android APK.

## 5. Build the Android APK

Every push runs Android APK CI. It verifies that the Android project can be generated/synced and that assembleDebug produces a non-empty APK.

The release workflow runs automatically for a tag beginning with v, for example v0.1.0.

## 6. Manual APK release build

Open Actions -> Android APK Release -> Run workflow.
The workflow builds the APK. When manually started, it publishes a prerelease with an APK asset.

## 7. Versioned APK release

From a local checkout:

git checkout main
git pull
git tag v0.1.0
git push origin v0.1.0

GitHub Actions then builds the APK and attaches it directly to the GitHub Release.

The asset name is NIM-Hub-v0.1.0.apk.

GitHub Releases accepts uploaded files as release assets, so this APK is a direct .apk asset rather than an Actions artifact archive.

## 8. Important distinction

GitHub Actions artifact downloads are presented by GitHub as artifact archives. NIM Hub therefore does not use Actions artifacts as the product download.

NIM Hub uses GitHub Releases for APK distribution. The release asset itself is the APK file.

GitHub may also show GitHub-generated source-code archives on the release page. Those are automatically generated by GitHub and are not NIM Hub build artifacts.

## 9. Runtime credentials

The GitHub NVIDIA secret is for CI/smoke testing. Do not compile it into the Android application.
The installed Android app should talk to the personal gateway configured for runtime use.
