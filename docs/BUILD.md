# NIM Hub — Android Build and CI

## Product output
The only product build is an Android APK. The React/Vite layer is implementation detail; there are no standalone web, desktop or iOS release workflows.

## Every push
.github/workflows/android-ci.yml runs on every push and pull request.
It installs Node 22, Java 21 and Android SDK 36, builds the web layer, ensures the Capacitor Android platform exists, runs cap sync, builds assembleDebug, verifies the APK exists, and runs gateway tests.

## Release
.github/workflows/android-release.yml runs for v* tags or manual dispatch. It builds the APK and attaches it directly to a GitHub Release as NIM-Hub-<tag>.apk.

There is no project-created ZIP/TAR around the APK. GitHub may still show its own source-code archives on a Release page; those are generated by GitHub, not by NIM Hub.

## NVIDIA smoke test
The release workflow optionally calls NVIDIA /v1/models when the NVIDIA_API_KEY repository secret is configured. The secret is never embedded into the APK.

## Capacitor
The Android build currently uses Capacitor 8.5.2. Capacitor 8 requires Node 22+; Android development uses a current Android SDK and matching Capacitor target. Verify upstream requirements before major upgrades.
